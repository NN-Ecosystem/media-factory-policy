Privacy Policy

Effective Date: 2026-01-01

1. Overview

This application ("Media Factory") is an automation system used for publishing and managing media content across platforms such as YouTube, Facebook, and Pinterest.

2. Data We Access

We may access the following data through authorized APIs:

  • Access tokens (OAuth authentication)
  • Channel / Page / Board identifiers
  • Media metadata (title, description, tags)
  • Publishing and scheduling information

3. How We Use Data

Data is used only for:

  • Uploading and publishing content
  • Scheduling posts (where supported)
  • Retrieving analytics (if enabled)

4. Data Storage

Access tokens and configuration data are stored locally in a secure environment and are not shared with third parties.

5. Third-Party Services

This system interacts with:

  • YouTube Data API
  • Facebook Graph API
  • Pinterest API

6. Data Sharing

We do not sell, trade, or share user data with external parties.

7. Security

All tokens and credentials are stored securely and used only for authorized API requests.
